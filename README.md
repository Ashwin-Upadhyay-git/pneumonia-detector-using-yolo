# Pneumonia Detection Using YOLO

A machine learning project that leverages the YOLO (You Only Look Once) real-time object detection framework to identify and classify pneumonia in chest X-ray images. The model is trained to detect pneumonia regions with high accuracy and speed, making it suitable for automated medical imaging analysis.

**Key Features:**
- Real-time pneumonia detection using YOLO architecture
- Trained on chest X-ray datasets
- Fast inference suitable for clinical applications
- High accuracy in pneumonia classification

**Tech Stack:** Python, YOLO, Jupyter Notebook
